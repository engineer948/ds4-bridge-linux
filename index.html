Saf C, 0 Bağımlılık

Uygulama baştan aşağı saf ve monolithic C kullanılarak yazıldı. Python aracı veya ağır çalışma zamanı yoktur; komutlar mikrosaniyeler içinde işlenir.

Sıfır Memory Leak

Gereksiz dinamik bellek (malloc/free) kullanılmadı. Arka planda aylarca açık kalsa bile fazladan 1 Byte RAM tüketmez.

Canlı Tuş Eşleme

Tuşlarınızı oyundan çıkmadan, yapılandırma dosyası düzenlemeden doğrudan GTK menüsü üzerinden saniyeler içinde değiştirin.

Saniyeler içinde başlatın

Uygulamayı indirin ve hemen arka planda çalıştırın.

# Sürüm 0.6 Tray uygulamasını indirin
wget https://github.com/engineer948/ds4-bridge-linux/releases/download/0.6/ds4_bridge_tray

# Çalıştırma yetkisi verin ve başlatın
chmod +x ds4_bridge_tray && ./ds4_bridge_tray

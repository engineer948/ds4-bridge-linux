Get started

Ready in a minute.

One file. No installer, no drivers, nothing to compile. Download, make it executable, play.

Download AppImage

Prefer the file manager? Right-click → Properties → Permissions → "Allow executing file as program". Also as a plain executable or from source.

# 1. Download
$ wget https://github.com/engineer948/ds4-bridge-linux/releases/download/1.0/DS4_Bridge-1.0-x86_64.AppImage

# 2. Make it executable
$ chmod +x DS4_Bridge-1.0-x86_64.AppImage

# 3. Start it and plug in your controller
$ ./DS4_Bridge-1.0-x86_64.AppImage --start

FAQ

Questions? Answers.

Is DS4 Bridge free?

Yes. It is free and open source under the MIT License: you can use, modify and share it, as long as the copyright notice stays.

My game sees two controllers.

DS4 Bridge takes over the physical controller so games only see the virtual one. If another program opened the controller first, stop and start the bridge from the tray menu.

It says it can't open /dev/uinput.

The app offers to install the required permission rule and asks for your password once. You can also use "Fix /dev/uinput Permissions…" in the tray menu. If it still fails, log out and back in.

My stick moves on its own.

Open Controller Test from the tray menu and watch the hollow dot without touching the stick. Raise that stick's deadzone until the filled dot stays centered.

Gyro aiming doesn't work.

Many clones have no working motion sensors. Settings → Gyro shows whether sensors were found on your controller.

Does it collect any data?

No. DS4 Bridge works completely offline and does not collect, store or send any personal data.

Is there a Windows or macOS version?

No. DS4 Bridge is built on the Linux input system and is Linux-only.

Is the download safe?

The full source code is public, and the 1.0 AppImage has been scanned on VirusTotal.
